雀魂直播控制中心 0.292 · 调优测试版（调优3）

打开方式

先关闭旧版控制中心，再双击本文件夹的“雀魂直播控制中心-v0.292.exe”。
程序、Assets 和 Backend 需要放在同一文件夹，不要只移动 EXE。
Windows x64 自包含便携版，无需安装 .NET；实时预览使用系统 WebView2。

本轮优化

1. 确认修改时显示保存状态；文件保存成功后才清除草稿、同步画面。保存失败会保留修改，可再次确认。
2. 保存期间暂时锁定编辑，避免重复提交；保存完成后恢复。
3. 逐局报告写入失败后保留内存记录，后续收到数据时重试。重复结算去重，迟到的选手姓名会补入报告。
4. 对局记录没有数据时显示明确提示；写入失败持续显示原因。
5. 竖排头像样式中的长昵称在原区域内自动分行；选手卡输入框和按钮增加可区分的辅助名称。
6. 非法图片路径不会阻止启动；CSV 中的昵称等文本按文本导出，原值保留在 JSON。
7. 退出时只关闭本程序自己启动的后台，保留外部已运行的后台。

操作说明

顶部只有雀魂账号已登录且连接正常时才显示“已连接”；本地 OBS 服务启动不代表观战登录成功。
点击“观战登录”完成登录，再输入大会 ID 获取对局。
点击“延迟/实时观战”选择下次观战方式、设置画面延迟。
四张选手卡横向排列，右上角显示上传头像的缩略图。选手资料和此前累计精算点用红色“确认修改”统一保存并同步。
实时预览为独立窗口，禁止单独关闭，随主程序退出；“实时预览”入口用于找回窗口。
OBS 样式选择后直接同步，不再提供横排选手卡或额外确认切换按钮。

逐局报告

从开始观战时记录实际收到的和牌、流局及对局结束事件，不补造加入观战前的事件。
包括局数、本场、赢家、可确认的放铳者、自摸/荣和、公开手牌、副露、和牌张、符数、番数、役种、原始点数及四家分数变化。
多家荣和保留全部赢家。未收到的字段显示“未提供”；不根据分数变化猜测结果。
JSON 保留原始公开结算字段；点数按 API 原值记录，不重复叠加供托或本场。
自动保存 CSV、JSON、TXT 到程序目录下的 reports；在“对局记录”中可以打开目录。
外部观战后台也须提供 round-results 能力，才能取得这些逐局详情。

OBS 浏览器源：http://127.0.0.1:17657/overlay
画布：1920×1080；背景透明。
配置：v0.292-settings.json，兼容读取同目录旧版 v29.2、v29.1、v29 配置。
沿用旧设置和图片时，可把旧目录的 v0.292-settings.json、Assets 复制过来。
本交付包使用正式端口，不含模拟服务、测试账号、历史报告或用户配置。
