雀魂直播控制中心 0.292 · 芙莉莲静态头像框测试版

新增 OBS 样式：竖排头像·芙莉莲

在主窗口“OBS 样式”下拉框中选择“竖排头像·芙莉莲”，选择后直接同步预览及 OBS。
新样式沿用竖排头像的四家位置、姓名和精算点布局，使用所提供的原始透明头像框 PNG。
头像框与立直提示均保持静态，没有头像框环绕动画；立直时仍有静态红圈。
其它原有 OBS 样式保留。原有选手自定义头像框/隐藏框设置仍可在“选手设置”中选择。

本轮检查

111 项测试通过（包括新样式保存、立即切换发布、旧枚举值兼容检查）；Release 编译完成。
本机示例 OBS 页面已检查四家头像框引用、头像圆孔对齐，以及框/立直圈无动画、环绕装饰隐藏。
原头像框 PNG 未重绘或修改像素。示例预览使用演示头像与姓名，不连接真实账号。
未执行真实账号登录、实际对局观战或 OBS 客户端播出验证。

打开方式

关闭旧版后，双击本文件夹“雀魂直播控制中心-v0.292.exe”。EXE、Assets 和 Backend 应放在同一文件夹。
Windows x64 自包含便携版；实时预览需要系统 WebView2。

雀魂直播控制中心 0.292 · 调优测试版（调优4）

打开方式

先关闭旧版控制中心，再双击“雀魂直播控制中心-v0.292.exe”。
EXE、Assets、Backend 需要放在同一文件夹。Windows x64 自包含便携版，无需安装 .NET；预览使用系统 WebView2。

本轮界面优化

1. 顶部四个入口等宽排列，增加用途说明，统一间距和操作区域。
2. 四张选手卡统一对齐；姓名占用整行区域，允许换行；持有点数使用大号数字与千位分隔。
3. 右上角保留 72×72 头像预览；累计精算点输入框、上传头像及选手设置按钮保持一致位置。
4. 确认区固定在底部；有待确认修改时加强边框提示；窄窗口通过滚动查看选手区域。
5. 观战登录分成账号登录、大会对局两块，空列表给出明确指引。
6. 弹窗统一标题、说明和表单间距；逐局记录强化局数、和牌结果、手牌与役种的层次。
7. 输入框、下拉框、复选框、列表和滚动条统一为深色样式，并保留键盘焦点提示。
8. 修正深色界面中禁用列表变白、输入文字被内边距裁切的问题。

操作说明

顶部只有雀魂账号已登录且连接正常时才显示“已连接”；本地 OBS 服务启动不代表观战登录成功。
点击“观战登录”完成登录，再输入大会 ID 获取对局。
点击“延迟/实时观战”选择下次观战方式、设置画面延迟。
四张选手卡横向排列，右上角显示上传头像的缩略图。选手资料和此前累计精算点用红色“确认修改”统一保存并同步。
实时预览为独立窗口，禁止单独关闭，随主程序退出；“实时预览”入口用于找回窗口。
OBS 样式选择后直接同步，不再提供横排选手卡或额外确认切换按钮。

逐局报告

从开始观战时记录实际收到的和牌、流局及对局结束事件，不补造加入观战前的事件。
包括局数、本场、赢家、可确认的放铳者、自摸/荣和、公开手牌、副露、和牌张、符数、番数、役种、原始点数及四家分数变化。
多家荣和保留全部赢家。未收到的字段显示“未提供”；不根据分数变化猜测结果。
JSON 保留原始公开结算字段；点数按 API 原值记录，不重复叠加供托或本场。
自动保存 CSV、JSON、TXT 到程序目录下的 reports；在“对局记录”中可以打开目录。
外部观战后台也须提供 round-results 能力，才能取得这些逐局详情。

沿用旧设置和图片时，可把旧目录的 v0.292-settings.json、Assets 复制过来。
