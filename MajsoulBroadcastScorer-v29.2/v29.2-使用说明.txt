雀魂直播控制中心 v29.2 · 赛事展示版

新样式：竖排头像·赛事展示

1. OBS 样式下拉框选择“竖排头像·赛事展示”。
2. 名称内容可选“所属队伍”或“选手姓名”。
3. 数值内容可选“当前分数（持有点数）”或“精算点”。
4. 右侧先预览；点击“确认切换到 OBS”才会更新播出样式及展示选项。
5. 默认组合为“所属队伍＋当前分数”。当前分数显示 API 原始持有点数，不带正号、pt 或精算换算，不受精算点显示开关影响。
6. 队伍从 API players[].teamName 获取，按固定 seat 对应。队伍暂未返回时显示“暂无队伍”。
7. 队伍可手动修改，点击“确认更新选手资料”后生效并锁定；点击对应“恢复 API”并确认资料后重新跟随 API。
8. 旧版手动填写的队伍会作为手动锁定保留；要改用 API 队伍请点击“恢复 API”。

原有竖排头像、队伍模式、横排选手卡、分差与逆转保留。
新样式沿用当前美术、40 秒慢速平滑外环及星光扫光。
本版附带已支持队伍名的新版无界面观战模块；如已有外部观战程序占用 7998，会读取它的数据，不会强行关闭它。

启动：雀魂直播控制中心-v29.2.exe（请先关闭其他 v29 系列显示程序）。
OBS 地址：http://127.0.0.1:17657/overlay，宽高 1920×1080；沿用浏览器源时刷新一次页面。
配置：v29.2-settings.json，可兼容同目录的 v29.1-settings.json 或 v29-settings.json；旧文件不会自动覆盖。
请整个解压使用。Windows x64 无需另装 .NET，实时预览仍使用系统 WebView2。
